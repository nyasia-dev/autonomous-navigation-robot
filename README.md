\# Autonomous Navigation Robot



\## Overview



This project is a ROS2-based autonomous navigation robot built using:



\- Raspberry Pi

\- L298N Motor Driver

\- RPLIDAR A1

\- ROS2 Jazzy

\- Ubuntu Linux



\## Goals



\- Autonomous navigation

\- Obstacle avoidance

\- SLAM mapping

\- ROS2 integration

Currently in development.
